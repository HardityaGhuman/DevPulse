**DevPulse** is an AI powered developer intelligence platform designed to streamline GitHub workflows. It provides developers with instant code reviews, automated pull request analysis, and scheduled activity digests powered by Google Gemini.

> **Live Demo:** [https://dev-pulse-steel.vercel.app/](https://dev-pulse-steel.vercel.app/)

---

## The Problem It Solves
Code reviews take time, and staying up to date with a team's GitHub activity can be tedious. DevPulse acts as an automated "AI Assistant Developer" for engineering teams. It can instantly review code snippets, analyze full Pull Requests for security and bugs, and automatically email developers a beautifully formatted summary of their weekly GitHub activity. 

## Key Features
- **AI-Powered Code Reviews:** Paste snippets or provide a GitHub PR URL to get instant feedback on bugs, security, complexity, and best practices.
- **Shareable Review History:** All reviews are securely saved and can be shared publicly via unique, secure tokens.
- **GitHub Activity Tracking:** Authenticated users get a dashboard view of their recent repository activity.
- **Automated Developer Digests:** Users can opt-in to Daily or Weekly email summaries of their GitHub activity, generated by AI.
- **Secure Authentication:** Seamless GitHub OAuth integration via Clerk.

## Tech Stack & Architecture (For Developers)

DevPulse is built using a modern, decoupled client-server architecture.

### Frontend
- **Framework:** React + Vite
- **Styling:** Tailwind CSS + Framer Motion (for fluid, modern animations)
- **Icons:** Lucide React

### Backend
- **Framework:** FastAPI (Python)
- **Database:** PostgreSQL (hosted on Supabase)
- **AI Integration:** Google Gemini 2.5 Flash
- **Background Jobs:** APScheduler (for cron-based email digests)
- **Email Delivery:** Resend / SMTP

### System Design Highlights
- **JWT-based Auth:** Uses Clerk to issue JWTs. The FastAPI backend verifies these tokens via Clerk's JWKS endpoint to secure all API routes.
- **Background Task Scheduling:** A dedicated `APScheduler` job runs autonomously on the backend to aggregate user data and dispatch emails without blocking the main event loop.
- **Split Deployment Strategy:** To optimize for cost and performance, the stateless frontend is hosted on Vercel's edge network, while the long-running Python backend (requiring continuous background processing) is deployed as a Web Service on Render.

## Getting Started (Local Development)

### Prerequisites
- Python 3.10+
- Node.js 20+
- API Keys for: Supabase, Clerk, Google Gemini, and Resend

### 1. Database Setup
1. Create a Supabase project.
2. Run the SQL located in `database/schema.sql` in the Supabase SQL Editor.

### 2. Backend Setup
```bash
git clone <your-repo-url>
cd DevPulse/backend

# Create virtual environment and install dependencies
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Configure environment variables (copy .env.example)
cp .env.example .env
```
*Fill in the `.env` file with your respective API keys.*

Start the FastAPI server:
```bash
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend Setup
In a new terminal:
```bash
cd DevPulse/frontend

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
```
*Fill in `VITE_CLERK_PUBLISHABLE_KEY` and set `VITE_API_BASE_URL=http://localhost:8000`.*

Start the Vite development server:
```bash
npm run dev
```
